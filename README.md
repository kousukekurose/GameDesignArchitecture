# ゲームアーキテクチャ設計プロジェクト

## プロジェクト概要
Unityを使用したモダンなゲーム開発アーキテクチャの実装デモンストレーション。プロダクション環境に適した設計パターン、DIコンテナ、イベント駆動アーキテクチャを適用したコードベースです。

## 技術スタック
- **Unity 6000.5.7f1** - ゲームエンジン
- **VContainer** - DIコンテナ
- **MessagePipe** - 高性能イベントバス
- **R3** - リアクティブプログラミング
- **UniTask** - 非同期処理
- **State Pattern** - デザインパターン

## 実装予定のアーキテクチャパターン

### デザインパターン
- **State Pattern**: Player/Enemy/GameManagerの状態管理（実装済み）
- **Dependency Injection**: VContainerによる疎結合化（実装予定）
- **Event-Driven Architecture**: MessagePipeによるコンポーネント間通信（実装予定）
- **Interface-Based Design**: SOLID原則に基づいた設計（一部実装済み）

### コード品質
- ✅ インターフェースベース設計（テスト容易性）
- 🔄 シングルトンの排除（DIコンテナ化予定）
- ✅ 非同期処理の適切な使用
- ✅ メモリ管理と適切な破棄
- ✅ データとロジックの分離

## プロジェクト構成
```
Assets/Script/
├── Container/          # VContainer設定
├── Events/             # MessagePipeイベント定義
├── Interfaces/         # DI用インターフェース
├── Player/             # プレイヤーシステム
├── Enemy/              # 敵AIシステム
├── Stage/              # ゲーム状態管理
├── Audio/              # オーディオ管理
└── Shared/             # 共通インターフェース
```

## 技術的な改善点（実装予定）

### シングルトンからDIコンテナへの移行
- **課題**: シングルトン多用によるテスト困難さと強い結合
- **解決策**: VContainerによるコンストラクタインジェクション（実装予定）
- **期待される成果**: テスト容易性向上、システム間の結合低減

### イベントシステムの最適化
- **課題**: 静的R3 Subjectによるメモリリークリスク
- **解決策**: MessagePipeによるライフタイムスコープ管理（実装予定）
- **期待される成果**: メモリ効率の良いイベントシステム
